# 统一桌面版实现存档

状态：**暂缓，保留在 `archive/unified-desktop-tauri` 分支**。记录日期：2026-10-01。

作者认为在软件中引入浏览器 / WebView 层会使方案偏重，因此暂时搁置这次桌面统一实现。本分支保存代码、构建工具和验收记录，便于以后重新评估；当前不合入主线，不发布桌面版本，也不替换现有 Swift 生产壳。

## 此次变更

新增 `packages/desktop`，使用 Tauri 2 管理窗口、托盘及随包 Go 后端。Tauri 复用系统 WebView，单个窗口加载随应用打包的现有 React WebUI；Go 仍内嵌同一前端，继续支持普通浏览器、服务器二进制和 Docker 分发。

- 桌面设置融入原前端的“运行配置 → 桌面应用”，登录页复用设置弹窗。没有单独的管理页面；服务停止时，原前端仍可进行恢复操作。
- 软件只启动并管理随包后端，不提供选择外部二进制或连接已有服务的功能。允许选择旧数据目录，用于直接复用配置、数据库、密钥和附件。
- 提供单实例、托盘、后台运行、服务启停、固定端口、日志与目录入口、复制 API 地址和面板令牌、开机启动。登录仍需手动输入令牌。
- 健康检查验证后端 PID 和数据库状态；异常退出最多恢复三次。桌面模式通过 stdin EOF 触发现有 Go 优雅关停，避免壳异常退出后遗留服务。
- 原生权限仅授予打包页面；普通浏览器 WebUI 不获得桌面权限。API、媒体和流式请求使用应用自己管理的后端地址。
- 采用官方签名更新插件，下载、验签完成后才停止服务并安装整包；macOS 安装失败时恢复应用备份。壳、Go 和 WebUI 随同一版本更新。
- 新增三端双架构构建及手动预发布工作流。macOS 保留旧应用标识、可执行文件名与通用 DMG；Windows 使用 NSIS，Linux 使用 AppImage。现有生产发布流程继续保留。

## 已验证与未完成项

本次实现完成时，Go 全套测试、Rust 13 项检查、Chromium / WebKit 合计 44 项相关回归及 9 项发行检查通过。macOS Apple Silicon 隔离应用实测了登录、统一设置、服务启停、端口变更、文件下载、单实例、退出和父进程异常退出。

签名本地更新夹具覆盖错误签名、取消、离线、安装失败恢复及 Tauri `.1 → .2` 成功升级；旧 Swift 安装器已验证新通用 DMG 的校验、提取和替换兼容。配置、密钥、附件及数据库的验证结果见[构建与验收文档](desktop-testing.md#本地验收记录)。

Windows / Linux 双架构、macOS Intel 真机安装、开机启动迁移及旧 Swift 完整网络升级仍待验收。CI 签名 Secrets 尚需维护者配置；没有发布 Release 或变更稳定更新入口。跨平台体积、内存与启动开销尚未形成完整对比。

## 如需重新评估

先明确是否继续接受以 WebView 承载 UI 的产品形态，再依据[验收清单](desktop-testing.md#自动检查与真机验收)补齐平台和升级验证。若仅复用其中的后端关停或构建改进，可单独评估对应改动，无需整体推广桌面方案。

构建命令、签名配置及详细记录见 [desktop-testing.md](desktop-testing.md)；英文参考见 [desktop-testing.en.md](desktop-testing.en.md)。
